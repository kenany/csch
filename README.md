# csch

Calculate the hyperbolic cosecant of a number.

## Example

```javascript
import { csch } from 'csch';

csch(Math.PI);
// => 0.08658953753004692
```

## Installation

```bash
$ npm install csch
```

## API

```javascript
import { csch } from 'csch';
```

### `csch(x: number)`

Given a _Number_ `x`, returns the hyperbolic cosecant of `x` as a _Number_.
